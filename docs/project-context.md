# 프로젝트 맥락과 설계 결정

작성일: 2026-10-29. 현재 저장소가 후속 작업의 기준 위치다. 대화 원문을 옮긴 문서가 아니라, 설계에 필요한 요구사항·근거·남은 질문만 정리했다.

현재 보유 제품은 사용자 확인 기준 NovelKeys 최신 판매 버전의 No.1/60 WK이며 WT60-A와 호환된다. PCB와 GH60의 호환성도 사용자 확인 완료로 두고 재확인 작업에서 제외한다. 정확한 리비전과 기존 공개 보강판 CAD의 실물 적합성은 아직 확인되지 않았다. 사용자는 외부 트랙볼을 이미 충분히 사용했으며 이번 프로젝트의 목적은 G/H 사이 중앙 통합이다. 외부 별도 장치는 후보에서 제외한다. 2026-10-31 사용자 위임에 따라 이번 제작 시제품은 34mm 볼, cocot36plus를 참고한 롤러와 하부 수평 센서, 62키 배열로 정한다. [실현 가능성과 대안 조사](feasibility.md)의 작은 볼과 터치패드는 과거 비교 자료로 유지한다. 시제품 선택은 실제 케이스 수납과 센서 동작이 확인되었다는 뜻이 아니다.

## 2. 결정과 이유

1. **2026-10-30 사용자 결정에 따라 15u·중앙 3u·62키를 개발 우선안으로 사용하고 65키는 비교용으로 유지**한다. 하단 중앙 M1/M2는 각각 1.5u이며 M3 물리 키는 없다. 두 중심은 mm 단위로 M1=(-14.2875,38.1), M2=(14.2875,38.1)이며 명목 너비 합계는 3u다. `layout.json`의 `rear_clearance`는 65키안에서 상단 중앙 Vol-/Mute/Vol+만 제거해 중앙 빈 명목 영역을 3열 × 4행, 57.15 × 76.20mm로 늘린다. 볼 지름 34mm와 중심 `(0, 0)`, G/H x=±38.10mm, 하단 1.5u M1/M2와 나머지 키는 그대로다. 추가한 뒤쪽 19.05mm는 센서·배선, 재료를 남긴 지지 브리지와 넓은 체결 간격을 검토하기 위한 공간이다. 키 제거 자체는 강성 향상을 보증하지 않으며 전체 직사각형 절개는 오히려 강성을 낮출 수 있다. 50×50mm 임시 예약 영역과 미확정 수직 공간은 바꾸지 않는다. 기존 산출물의 `preferred`는 65키의 데이터 식별자로 유지하며 현재 개발 우선순위를 뜻하지 않는다.
2. **14u·중앙 2u·64키는 비교만 하고 보류**한다. Ø34 볼 자체는 들어가지만, 홀더/센서/나사까지 포함한 수납 근거가 없다. 50mm 예약 영역은 키캡과 5.425mm 겹친다. 실물의 높이별 외곽이 더 작으면 재검토할 수 있다.
3. **2026-10-31 사용자 요청에 따라 cocot 방식과 62키를 제작 시제품의 기준으로 선택**한다. 34mm 볼과 62키 좌표를 유지하고 베어링 롤러 3개 및 하부 수평 센서를 채택한다. 상부 링과 스크롤 링은 생략하며 센서는 기존 Keyball 계열 모듈을 재사용하는 조건부 회로를 유지한다. cocot의 센서를 메인 PCB에 직접 실장하는 회로는 도입하지 않는다. 공개된 센서 기판 외곽과 실제 홀더 외피는 다른 정보다. 원형 Ploopy Nano/Mini는 38.10mm, Classic은 44.45mm여서 34mm 드롭인 대체품이 아니다. Charybdis는 같은 34mm지만 별도 장착 설계가 필요하다. 제품별 센서·지지 구조·라이선스는 [별도 비교](alternatives-and-licenses.md)에 기록하며 다른 중앙 장치는 과거 대안으로 남긴다.
4. **볼+센서는 같은 강체에 고정**한다. 2026-10-30 사용자 계획에 따라 새 플레이트는 알루미늄을 사용하며, 하나의 모듈로 장착하고 중앙 보강을 검토한다. 현재 시제품은 1.5mm 6061-T6 판재를 선택하지만 모델의 두께는 강성 검증 결과가 아니다. 브래킷 재질은 별도로 정한다. 공간·강성 결과에 따라 기존 케이스 체결점을 쓰는 가역 브래킷도 검토한다. 볼은 케이스, 센서는 휘는 플레이트에 따로 고정하지 않는다.
5. **GH60 공개 KiCad 도면을 출발점으로 새 PCB를 설계한다.** 보강판이 케이스에 결합하고 PCB는 스위치를 통해 지지되므로, WT60-A와의 작은 외곽 치수 차이만으로 GH60 기반 설계를 배제하지 않는다. Poker2 규격 WT60-D가 USB-C 제거와 JST 커넥터 추가 후 No.1/60에 장착된다는 제품 설명을 근거로 삼는다. WT60-A의 정확한 PCB CAD 확보를 설계 시작의 선행 조건으로 두지 않는다. 사용할 GH60 파일과 호환 근거, 도터보드 연결 조건은 [PCB 설계 출발점](../design/preliminary/design.md#pcb-설계-출발점)에 기록한다. 최종 외곽과 중앙 개구, 부품 배치 및 제조 데이터는 FreeCAD에서 공식 STEP와 실측 모듈의 기구 스택을 대조한 뒤 확정하며, 예비 SVG를 제조 DXF로 바꿔 바로 발주하지 않는다.

실측 전에 회로도, 키 매트릭스, 스위치 배치와 주요 회로 배선 초안을 진행한다. 구현 순서, RP2040 등 초안의 우선안과 단계별 완료 기준은 [PCB 구현 계획](pcb-implementation-plan.md)을 따른다. 실물 확인은 GitHub 이슈 #1부터 #6에서 관리하며, 기구와 인터페이스가 미확정인 상태를 제조 준비 완료로 보고하지 않는다.

2026-10-31 사용자 요청에 따라 [출력용 독립 홀더 시제품](../design/printable-holder/README.md)을 사용한다. 34mm 볼과 베어링 롤러 3개, 수평 센서를 같은 받침에 고정하며 상부 링은 생략한다. 이후 사용자가 하부 여유를 Mill-Max 3305/3306 수준으로 제한했으므로, 보강판 아래 19..24mm를 요구하던 구조는 폐기하고 받침을 보강판 위에 놓는다. 짧은 3305-0의 명목 길이 2.67mm에서 플랜지 0.25mm와 PCB 1.6mm를 뺀 0.82mm를 PCB 아래 돌출 한도로 가정한다. [치수 근거](../design/preliminary/sources/README.md#shallow-clearance-reference)는 실제 케이스 깊이 측정값이 아니며 3306의 규격은 확인하지 못했다. 볼 중심은 Z=23.5mm, 위끝은 Z=40.5mm이고 센서 지지대 나사 아래끝은 Z=-7mm를 목표로 한다. PCB 윗면 Z=-5mm와 아래면 Z=-6.6mm를 기준으로 나사 돌출은 0.4mm다. 광학 기준면, 센서 부품과 케이블, 출력 공차 및 높은 볼의 사용성은 실물 시험이 필요하다.

62키 DRAFT H는 48 x 48mm R1 PCB 개구를 유지하고 중앙 뒤쪽 빈 공간에 윗면 전자부품을 배치한다. 하부 돌출을 줄이기 위해 MCU, flash, 전원, 커넥터와 다이오드를 F.Cu로 옮긴다. 보강판은 36 x 36mm R3 중앙 창과 (±21,±21)mm M2 체결 구멍을 사용하며, 뒤쪽 전자부품과 커넥터에 필요한 별도 개구를 둔다. 과거 Keyball46의 TPS73601/TXS0102 회로에 +3V3를 공급하는 [조건부 인터페이스](../design/pcb/README.md#sensor-interface-remains-unresolved)는 유지한다. 실제 센서와 케이블 확인 및 전원 시험은 조립 전 조건이며 65키 DRAFT E는 비교용으로 보존한다.

65키 KiCad 원본은 `design/pcb/keycult65.*`, 62키 원본은 `design/pcb/62/keycult62.*`에 둔다. 65키는 기존 왼쪽 하부 회로를 유지하고, 62키는 DRAFT H에서 뒤쪽 중앙 윗면 회로로 재배치한다. 두 배열 모두 하단 SW59/D59를 제거하고 SW58/SW60의 중심을 옮기며, 다른 reference 번호는 유지한다. 62키에서는 SW7-SW9와 D7-D9도 제거한다. COL6과 COL8은 하단 키에 연결되고, 62키의 COL7은 키가 없으므로 GP16을 회로도에서 NC로 표시한다. 공통 15열 GPIO 순서는 유지하고 펌웨어에서는 해당 열을 KC_NO로 둔다. 스위치를 장착하지 않는 것은 전기적으로 가능하지만, 이전 PCB에는 해당 영역 아래에 공통 회로가 있으므로 기존 PCB를 잘라 공간을 확보해서는 안 된다.

65키 PCB의 부품·구리 예약 영역은 50 x 50mm다. 62키 DRAFT H의 금지 영역은 48 x 48mm PCB 개구에서 0.25mm 확장한 배열 좌표 x/y=-24.25..24.25mm, PCB 좌표 x=155.75..204.25mm와 y=75.75..124.25mm다. 이전의 57.15 x 75.875mm 전체 빈 키 영역은 전자부품을 위에 배치하기 위해 더 이상 구리 금지 영역으로 사용하지 않는다. 배열 `(0,0)`은 PCB `(180,100)mm`이며 +Y는 하단 방향이다. 기존 50mm 임시 조립 예약 영역과 실제 PCB 개구를 구분한다. J2는 하부 수평 센서와 케이블로 연결하는 JST GH 7핀 호스트 커넥터이며 실제 센서 쪽 커넥터는 미확정이다.

USB는 [WT 호환 및 UDB 리비전별 조사](../design/pcb/sources.md#usb-daughterboard-evidence)와 2026-10-30 사용자 승인에 따라 UDB C5-JSH를 그대로 사용하는 가정으로 설계한다. 이는 보유 Keycult 순정 도터보드의 리비전이나 회로를 실측으로 확인했다는 뜻이 아니다. DRAFT E도 외부 조립체 DB1을 회로도에만 표시하며 메인 PCB footprint를 두지 않는다. C5-JSH의 CC 5.1kΩ 저항 2개, TPD4E05U06 ESD 보호, ASMD1206-150 PTC, SMF6.0A TVS 및 실드의 GND 직결을 외부 보드가 담당한다. 메인 PCB의 F1 500mA와 USB 27Ω 직렬 저항, 기존 공통 부품 배치를 유지하고 하단 1.5u M1/M2 좌표에 맞춰 매트릭스를 다시 배선한다. J1 측 USB 배선 규칙과 접지 귀환 경로도 적용한다.

두 PCB의 J1은 JST SM04B-SRSS-TB(LF)(SN)이며 핀은 1=VBUS_USB(외부 PTC 이후), 2=D-, 3=D+, 4=GND다. 케이블은 번호 기준 1:1 연결이다. 62키 DRAFT H는 얕은 하부 조건 때문에 J1을 윗면 뒤쪽으로 재배치하며 최신 원점과 방향은 [PCB 안내](../design/pcb/README.md)를 따른다. 65키는 기존 하단면 왼쪽 배치를 유지한다. 필요한 길이의 케이블을 구할 수 있으므로 기존 케이블의 도달 거리는 제약에서 제외한다. 실제 커넥터 체결, 케이스 통로, 케이블 굴곡, 부하와 USB 신호 품질은 조립 시험으로 확인한다.

2026-10-30 [실물 없이 수행한 전기 검토](../design/pcb/README.md#power-and-usb-desk-review)는 호스트 110mA에 센서 40/50/70mA를 더한 총 150/160/180mA 시나리오를 비교한다. 주변 50 C 모델의 접합 온도는 각각 111.73/115.78/123.88 C다. 부품 최대 소비전류나 실제 사용 가능한 전류를 보증한 값은 아니며 센서가 5V 모듈이면 별도 계산한다. DRAFT E는 JLC04161H-7628 후보의 구리·유전체 모델을 CAD에 명시하고, 긴 USB 구간을 In2.Cu에서 F.Cu로 옮겨 In1.Cu 접지를 참조하도록 한다. J1 측 데이터 배선은 선폭 0.29mm, 최소 가장자리 간격 0.2mm를 사용하며 B.Cu에는 짧은 탈출 배선만 둔다. 접지 비아와 B.Cu 접지면을 추가하고 In1.Cu 상단 경계를 확장한다. [적용한 USB 배선과 검토 한계](../design/pcb/README.md#usb-routing-findings)를 따르며, 이 모델은 제조사 승인 stackup이나 임피던스 검증 완료를 뜻하지 않는다.

## 3. 확인된 값, 유도한 값, 가정한 값

2026-10-30 [로컬 FreeCAD 보강판 초안](../design/preliminary/design.md#로컬-freecad-보강판-초안)은 공식 NoLeaf의 외곽을 유지하면서 65키·62키 PCB의 스위치 중심에 맞춰 재생성한다. 중앙 지름 40mm 개구, 48 x 48 x 3mm 프레임과 네 점의 M2 체결 검토는 자체 설계 가정이며 실물 Keyball 홀더 치수가 아니다. 62키안은 뒤쪽 센서 고정부를 위한 재료를 더 남긴다. 중앙이 막힌 PCB는 윗면 z=-5mm와 기존 설명용 볼 중심 z=8mm를 가정하면 볼과 간섭한다. 65키는 중앙이 막힌 PCB와의 간섭을 유지하며, 기존 62키 로컬 모델은 DRAFT F의 개구를 반영한 과거 비교용이다. 현재 출력 홀더 FCStd는 DRAFT H의 48 x 48mm 개구와 위로 올린 볼 및 센서를 사용하며 이 과거 스택과 다르다. 이 개구도 실제 모듈에 맞는지는 확인하지 않았다. 볼과 센서는 같은 프레임에 고정하는 원칙을 유지하며 실제 홀더 고정 패턴, 광학 위치와 체결 스택은 미확정이다. 공식 형상을 포함하는 FCStd/STEP/DXF와 이미지는 `design/preliminary/sources/local/plate-study/`에만 생성한다.

| 상태 | 값 | 해석 |
|---|---|---|
| 자료 명시 | 외장 294.3×111mm, 앞 20.35mm / 뒤 35.8mm | **내부 개구부나 내부 깊이가 아님** [K1] |
| 공식 CAD에서 측정 | 플레이트 285.75×108.25×1.5mm | 108.25는 장착 탭 포함. 기본 직사각형 285.75×95.25mm [K2,K3] |
| 공개 도면의 참조 경계 | 일반 직사각형 285.75×108.25mm | 바운딩 치수만 사용하며 탭·코너·공식 윤곽은 재현하지 않음 |
| 자료 명시 | Rev.1은 플레이트 호환, 다른 케이스 부품 비호환 | WT60-A 및 USB-C daughterboard. 실제 보유 리비전은 미확정 [K1] |
| 자료/원본 확인 | 순정 Keyball의 34mm 볼과 뒤쪽 **수직 센서** | 원본 구조 [B1]. 현재 독립 시제품의 하부 수평 배치와 구분 |
| 공개 Gerber에서 측정 | 센서 PCB 22×25mm | Keyball46 공개 2022 자료 범위. 홀더 외곽도, 전체 조립 외피도 아님 [B2] |
| 채택 기준 | 피치 19.05mm | 공식 플레이트 인접 1u 스위치에서도 확인 |
| 유도 | 15u 키필드 285.75×95.25mm; G/H x=±38.10mm | 배열의 수학적 결과이며 케이스 수납 확인은 별개 |
| 유도 | 62키 옵션의 중앙 빈 명목 영역: x=-28.575..28.575mm, y=-47.625..28.575mm | 65키 기준안의 뒤쪽에 19.05mm 한 행을 추가. 홀더 외곽이나 절개 치수가 아님 |
| 가정 | 1u 키캡 18 x 18mm, 1.5u 키캡 27.525 x 18mm, 스위치 비교 사각형 14 x 14mm | 실제 키캡 하단·클립·핀·소켓·다이오드는 미검증 |
| 임시 예약 | 중앙 50×50mm | **실측 홀더 치수·플레이트/PCB 개구 치수 아님** |
| 표시상 가정 | 외장과 키필드를 동심 정렬 | 실물 기준점·플레이트 위치·개구부 오프셋으로 등록 필요 |
| 설명용 예 | 단면의 볼 중심 c=8mm | 실제 볼 중심 높이를 선택/확인한 값이 아님 |

출처 ID와 원문 URL은 [설계 문서](../design/preliminary/design.md#출처)를 따른다. 측정값·원본 해시는 [sources](../design/preliminary/sources/README.md)에 있다.

[케이스 참조 모델](../design/preliminary/design.md#케이스-참조-모델)은 과거 공개 외장 치수에 가정한 벽과 바닥, 상부 테두리와 개구부를 적용하고 보강판과 정렬한 별도 FreeCAD 사본이다. 사용자는 실측값이 없는 상태의 참조 모델 검토를 승인했다. 내부 치수와 정렬은 미확정 상태를 유지하며, 보강판과 참조 내벽의 겹침 및 체결 나사의 약 0.252mm 최소 간격은 이 가정에 따른 결과다. 실제 장착 홈이나 나사 보스를 재현하지 않으므로 실물 적합성 판정으로 사용하지 않는다.

## 4. 검증된 범위와 그 한계

- 모든 키 중심, 키 수, 피치, 키캡/스위치 비교 사각형의 쌍별 충돌, 볼–키 거리, 50mm 예약 영역–키 간격을 계산했다.
- 65키안은 볼–키캡 **12.10mm**, 예약 영역–키캡 **4.10mm**, 인접 키캡 **1.05mm**의 최소 평면 간격이다.
- 62키 옵션도 공개 평면 검사와 별도 1:1 A3 인쇄 자료로 비교한다. 과거 공식 윤곽 검사 기록은 이 새 옵션을 검증한 결과가 아니며, 장착 안정성과 실제 수납은 미확정이다.
- **현재 공개 검증**은 285.75×108.25mm 일반 직사각형 치수 경계 내 포함과 부품 간 평면 간격을 다룬다. 이 직사각형은 공식 플레이트 형상이 아니므로 탭·둥근 모서리에서의 실제 포함 관계를 증명하지 않는다.
- **과거 공식 윤곽 관측**은 [plate-containment.json](../design/preliminary/plate-containment.json)에 수치 기록으로 남겼다. 당시 66키안의 스위치 비교 사각형과 키캡은 모두 공식 DXF 윤곽 안에 있었고, 키캡–윤곽 최소는 모서리에서 **약 0.327mm**였다. 현재 공개 검증이 이 결과를 다시 계산하는 것은 아니다. 공식 DXF를 로컬 취득한 뒤 `uv run scripts/verify_official_contour.py`로 별도 재현하며, 정확한 좌표·재검사 출력은 Git에서 제외하는 `design/preliminary/sources/local/`에 저장한다.
- **직사각형 경계 포함 ≠ 정확한 플레이트 윤곽 포함 ≠ 케이스 개구부 통과 ≠ 조립 가능 ≠ 제조 검증 완료**다.
- 인쇄 PDF의 100mm 기준선은 내부 벡터로 검증했다. 프린터에서는 100% 실제 크기 출력 후 자로 재확인한다.

### 실물 확인과 최종 확정 순서

아래는 실측 이후의 기구 확정 순서다. 회로도와 PCB 초안은 이 순서와 독립적으로 [PCB 구현 계획](pcb-implementation-plan.md)에 따라 먼저 진행한다.

1. 위 치수와 리비전을 확보한다.
2. 62키 우선안의 A3 1:1 종이 배치를 실제 플레이트에 맞춰 G/H 간격·손가락 접근을 확인하고 필요하면 65키안과 비교한다. 뒤쪽 확보 공간은 센서·배선 및 지지체의 실제 외곽과 대조한다.
3. 실제 홀더의 STEP 또는 실측 모형으로 FreeCAD 합본 간섭 검사를 한다. 동일 강체의 센서·볼 광학 간격을 보존한다.
4. 플레이트 마운트 / 기존 체결점 브래킷 중 가능한 구조를 선택하고 휨·조립 경로를 확인한다.
5. 채택한 C5-JSH의 기구 적합성과 전원·USB 신호 품질을 검증하고 MCU/센서 전압·로직을 확정한다. 실제 핫스왑 소켓 채택 여부도 수직 여유를 보고 결정한다.
6. GH60 도면을 바탕으로 시작한 KiCad 회로/PCB의 외곽과 부품 배치를 확정하고, 실제 개구·체결 도면, QMK 포팅 및 제조 검토를 진행한다.

## 6. 자료 관리

이 저장소에 들어 있는 것은 검토 가능한 설계 맥락과 독립 레이아웃 산출물이다. 원본 대화·개인 메모·실행 환경 인증 정보는 옮기지 않았다. 원본 CAD/센서 파일은 출처·해시와 로컬 다운로드 스크립트로 참조한다. 공개 SVG/HTML/PNG/PDF에는 공식 윤곽 대신 일반 직사각형 치수 경계만 넣는다. 정확한 윤곽 좌표 `design/preliminary/sources/local/measured-official-dxf.json`과 재검사 출력은 Git에서 제외한다. 형상을 복제하지 않는 STEP 바운딩 치수 요약과 과거 윤곽 검사의 수치 기록은 공개한다. 로컬 원본 사용도 Keycult 조건을 따르며, [라이선스 비교](alternatives-and-licenses.md)를 확인한다.

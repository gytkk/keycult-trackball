# PLA 시험 출력 요청

이 묶음은 키보드 중앙 트랙볼의 조립과 손가락 접근성을 확인하는 PLA/FDM 시제품이다. 실제 출력과 조립은 아직 시험하지 않았다. 최종 PA12 SLS/MJF 홀더나 알루미늄 보강판의 강성, 실제 Keycult 케이스 수납, 센서 추적 성능을 보증하지 않는다. 공식 케이스나 보강판 외곽을 복제한 파일은 포함하지 않는다.

## 먼저 확인할 것

- 프린터 기종, 노즐 지름, 사용 가능한 출력 영역과 PLA 프로파일을 확인한다. 기종을 모르는 상태이므로 G-code와 프린터별 슬라이서 프로젝트는 제공하지 않는다.
- 모든 STL은 mm 기준이며 배율은 100%다. 자동 크기 맞춤이나 전체 배율 변경으로 구멍을 맞추지 않는다. 가장 큰 부품인 받침대는 약 114.6 x 91.6 x 20mm다. 모든 부품을 한 출력판에 배치할 필요는 없다.
- PRINT-LIST.txt 또는 print-list.csv의 수량대로 출력한다. STL 13종, 예비분 포함 총 24개다. 수량은 전체 작업의 합계이며 시험편을 먼저 출력했다면 중복 출력하지 않는다.
- 작은 나사 구멍, 수평 축 구멍과 얇은 부품이 있으므로 슬라이서에서 누락되는 벽이나 막히는 구멍, 서포트 제거 경로를 확인한다. 기존 홀더는 PA12 공정을 기준으로 만든 형상이므로 PLA/FDM에서 그대로 출력 가능하다는 판정은 아니다.

## 파일과 수량

| STL 이름 | 수량 | 용도 |
| --- | ---: | --- |
| Cup-PROTOTYPE.stl | 1 | 실제 볼과 베어링을 받치는 홀더 |
| SensorCarriage-PROTOTYPE.stl | 1 | 센서 지지대 |
| SensorCap-PROTOTYPE.stl | 2 | 센서 고정 덮개 1개와 예비 1개 |
| SeatCoupon-PROTOTYPE.stl | 1 | 축과 나사 구멍 시험편 |
| SensorSpacer1-PROTOTYPE.stl | 2 | 4.5mm 센서 스페이서 |
| SensorSpacer2-PROTOTYPE.stl | 2 | 위와 같은 치수 |
| SensorSpacer3-PROTOTYPE.stl | 2 | 위와 같은 치수 |
| SensorSpacer4-PROTOTYPE.stl | 2 | 위와 같은 치수. 4.5mm는 합계 8개, 조립 4개와 예비 4개 |
| SensorSpacer3p75mm-PROTOTYPE.stl | 4 | 센서를 기본 위치보다 0.75mm 올리는 스페이서 |
| SensorSpacer3p0mm-PROTOTYPE.stl | 4 | 센서를 기본 위치보다 1.5mm 올리는 스페이서 |
| BenchPlate-PROTOTYPE.stl | 1 | 중앙 홀더와 주변 스위치 10개를 장착하는 시험판 |
| BenchStand-PROTOTYPE.stl | 1 | 시험판 가장자리를 받치는 바닥이 열린 받침대 |
| PCBOpeningGauge-PROTOTYPE.stl | 1 | 중앙 PCB 개구를 확인하는 두께 1.6mm 더미 |

SensorSpacer1부터 4는 높이가 다른 부품이 아니다. 네 파일 모두 높이 4.5mm이며 위치만 다르게 모델링한 원본에서 가져왔다. 3.75mm와 3.0mm는 별도 높이 후보다. 출력 후 높이별로 따로 포장하고 이름을 적는다. 스페이서 외경은 4.4mm, 구멍은 2.3mm이므로 출력 누락과 분실에 주의한다.

## 출력 순서와 조건

1. SeatCoupon을 먼저 출력한다. 30 x 12 x 4mm 시험편이며, 아래쪽 일렬 구멍은 왼쪽부터 지름 3.0/3.1/3.2mm다. 위쪽 두 구멍은 왼쪽 1.7mm 파일럿, 오른쪽 2.3mm 통과 구멍이다. 실제 축과 나사가 있으면 끼워 보고, 없으면 측정 가능한 치수와 사진을 남긴다. 이 수직 구멍 시험만으로 본체의 수평 축 구멍 적합성이 확정되지는 않는다.
2. 시험편 결과가 괜찮으면 나머지 부품을 출력한다. 한 번에 모두 출력해야 한다면 시험편 결과를 반영하지 못해 재출력이 필요할 수 있다. 구멍 크기나 전체 형상을 임의로 바꾸지 말고 먼저 알려준다.
3. PLA의 온도와 속도는 해당 프린터와 필라멘트의 검증된 프로파일을 쓴다. 적층 높이 0.15mm는 검토 시작점이며 확정 출력 조건은 아니다. 1.5mm 시험판, 1.6mm PCB 더미, 3.75mm 스페이서의 실제 슬라이싱 높이를 각각 확인한다.
4. 시험판과 PCB 더미는 넓은 평면을 바닥으로, 받침대는 넓은 밑면을 바닥으로 둔다. 스페이서는 구멍 축을 수직으로 둔다. 홀더와 센서 지지대는 서포트가 구멍과 센서 접촉면을 막지 않는 방향을 검토한다. STL은 Z=0에 놓았지만 출력 방향을 최적화한 슬라이서 파일은 아니다.
5. 얇은 판과 작은 스페이서는 슬라이서에서 내부가 빠짐없이 채워지는지 확인한다. 홀더의 기둥과 체결부는 벽 수, 적층 방향과 서포트 제거 시 파손 가능성을 검토한다. 필요하면 브림을 쓰되 접촉면과 구멍 가장자리를 손상시키지 않고 제거한다.
6. 출력 후 서포트를 제거하고 뒤틀림과 층 분리, 막힌 구멍을 확인한다. 나사산은 모델링하지 않았으므로 1.7mm 파일럿에 M2 나사가 무조건 들어간다고 가정하지 않는다. 탭 가공이나 실제 체결 시험은 조립자가 별도로 수행한다. 얇은 기둥을 힘으로 벌리거나 과도하게 조이지 않는다.

## 조립 확인

fixture-plan.svg는 시험판의 위쪽 보기다. T/Y가 뒤쪽, Del/M1/M2/Bksp가 앞쪽이다. 시험판은 110 x 87 x 1.5mm 독립 직사각형이며, 스위치 구멍은 14 x 14mm다. 스위치 클립과 출력 공차는 실물로 확인한다. 전체 키보드나 실제 케이스에 끼우는 보강판이 아니다.

1. 시험판을 받침대에서 뺀 상태로 홀더를 장착한다. 중앙 36 x 36mm R3 창과 42mm 정사각 피치의 지름 2.3mm 구멍 4개를 사용한다. M2x8 나사를 판 아래에서 위로 넣고 위쪽 너트로 고정한다.
2. 홀더의 베어링과 실제 볼을 조립하고, 필요하면 센서 지지대와 덮개를 장착한다. 실제 센서의 부품과 노출 도체가 지지대에 눌리지 않는지 먼저 확인한다. 센서가 없어도 기구와 사용성 시험은 가능하다.
3. 주변 스위치와 키캡을 끼운 뒤 시험판을 받침대에 올린다. 가장자리 턱은 한쪽 0.3mm 명목 간격으로 위치를 잡으며 잠금장치가 아니다. 받침대만 잡고 전체 조립체를 들어 올리지 않는다. 손가락으로 가볍게 조작하며 휘거나 깨지면 시험을 중단한다.
4. 받침대 위의 시험판 윗면은 책상에서 20mm다. 볼 위끝은 시험판 위 40.5mm다. 이 수평 지그는 실제 케이스의 타건 각도나 책상 기준 높이를 재현하지 않으므로 손가락의 상대 접근만 먼저 판단한다.
5. PCBOpeningGauge는 58 x 58 x 1.6mm이며 중앙 48 x 48mm R1 개구만 재현한다. 받침대 아래에서 손으로 올려 센서 지지대가 통과하는지 확인한다. 높이를 고정하는 체결부가 없으므로 매달아 두지 않는다. 설계상 PCB 윗면은 시험판 윗면보다 5mm 아래지만, 이 더미만으로 그 간격이나 실제 부품·핀·납땜 간섭을 검증할 수는 없다.
6. 센서 높이를 바꿀 때는 같은 높이의 스페이서 4개를 한 세트로 사용한다. 기본 4.5mm와 중간 3.75mm는 M2x10, 3.0mm는 M2x8 후보를 사용하며 실제 머리 높이와 나사 물림 길이를 확인한다. 기본 위치보다 센서를 아래로 내리지 않는다.

## 별도로 준비할 실제 부품

- 지름 34mm 트랙볼 1개, 내경 3 x 외경 8 x 폭 4mm 베어링 3개.
- M3x14 소켓 머리 나사와 M3 너트 각 3개. 베어링 내륜에만 닿는 금속 스페이서 6개: 내경 3.1, 외경 4, 두께 0.3mm 후보. 이것은 출력하는 센서 높이용 스페이서와 다른 부품이다.
- 보강판 체결용 M2x8과 M2 너트 각 4개, 센서 지지대용 M2x10 4개, 낮은 스페이서용 M2x8 4개, 덮개용 M2x5 2개. M2 소켓 머리는 지름 3.8mm와 높이 2mm 이하 후보로 검사했다.
- MX 계열 스위치 최대 10개, 1u 키캡 8개와 1.5u 키캡 2개. 일부 키만 끼워도 접근성을 비교할 수 있다.
- 센서 시험에는 실제 모듈과 확인된 케이블이 필요하다. 미확인 모듈에 전원을 연결하지 않는다. 이번 출력 요청에는 전기 조립과 전원 시험을 포함하지 않는다.

볼, 베어링, 금속 스페이서, 나사와 너트는 출력하지 않는다. 베어링 외륜과 실드가 홀더나 스페이서에 닿지 않고 자유롭게 돌아야 한다. 볼을 붙잡는 상부 링이 없으므로 기울이거나 뒤집기 전에 볼을 뺀다.

## 참조 파일과 검사 범위

holder-preview.svg는 기존 홀더의 조립·분해 모습이며 bench-preview.svg는 실제 볼과 키캡을 가정한 시험판 조립 모습이다. bench-assembly.FCStd는 FreeCAD에서 여는 시험판·받침대와 홀더 조립 참조이며 구매품 가정도 포함한다. PCBOpeningGauge는 기본적으로 숨겨져 있다. 이 조립 파일 전체를 출력하지 말고 STL과 수량표만 사용한다.

checks.json은 단일 솔리드, 메시 폐곡면과 연결성, STL 부피 오차, 기존 홀더와의 명목 간섭, 키 중심, 시험판 받침과 분리, PCB 더미 삽입 경로 및 입력 해시를 기록한다. 센서 높이별 나사와 간섭은 기존 홀더 검사도 다시 실행한다. 실제 출력, 슬라이서 경로, 강도, 센서 렌즈·커넥터, 실제 스위치 클립과 케이스는 검증하지 않는다.

저장소에서의 편집 원본은 scripts/build_print_request.py이며 기존 홀더 형상은 scripts/build_printable_holder.py를 사용한다. 두 경로는 프로젝트 루트 기준이다. 설치된 FreeCAD Python으로 프로젝트 루트에서 다음 명령을 실행하면 이 폴더의 추가 STL, 수량표, 검사 기록, 참조 CAD와 ZIP을 다시 만든다. 기존 홀더 STL은 해시와 형상을 검사한 뒤 ZIP에 복사하며 원본은 수정하지 않는다.

```bash
uv run --python /Applications/FreeCAD.app/Contents/Resources/bin/python scripts/build_print_request.py
```

EMAIL-DRAFT.txt는 전달용 메일 초안이다. 실제 메일 발송이나 출력 주문은 수행하지 않는다.
